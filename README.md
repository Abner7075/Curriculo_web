# 💻 Portfólio Pessoal — Abner Rocha

## 👨‍💻 Sobre o Projeto

Este projeto consiste na criação de uma **página de portfólio pessoal** utilizando HTML e CSS. A página apresenta informações sobre o desenvolvedor, suas habilidades, projetos realizados e uma área para contato.

A atividade foi desenvolvida durante o curso de **Desenvolvimento de Sistemas no SENAI**, com o objetivo de praticar a estruturação de uma página web utilizando HTML semântico, links, tabelas, imagens, formulários e estilização básica com CSS.

---

## 🎯 Objetivo da Atividade

O objetivo principal foi desenvolver uma página pessoal que simulasse um **portfólio de desenvolvedor web**, reunindo:

- 👤 Informações pessoais;
- 🛠️ Habilidades em desenvolvimento;
- 📂 Projetos realizados;
- 📊 Tabela para organização dos projetos;
- 📩 Formulário de contato;
- 📞 Informações de contato;
- 🎨 Estilização básica utilizando CSS.

---

## 🖥️ Estrutura do Site

### 🏠 Cabeçalho

O cabeçalho apresenta o nome do desenvolvedor e um menu de navegação com links para as principais seções da página:

- Sobre;
- Projetos;
- Contato.

### 👤 Sobre Mim

Nesta seção são apresentadas informações sobre o desenvolvedor, incluindo:

- Curso de Desenvolvimento de Sistemas no SENAI;
- Conhecimentos em HTML e CSS;
- Aprendizado de JavaScript;
- Principais habilidades desenvolvidas.

Também foi adicionada uma imagem de perfil utilizando a tag `<img>`.

### 📂 Meus Projetos

Os projetos são apresentados em uma tabela contendo quatro informações:

| Projeto | Tecnologia | Status |
|---|---|---|
| GameZone Retro | HTML | Concluído |
| Atividades de Lógica e Algoritmo | JavaScript | Concluído |
| Projeto Itaú | Figma | Concluído |

Cada projeto possui um link direcionando para seu respectivo repositório no GitHub.

### 📩 Entre em Contato

Foi criado um formulário para permitir que visitantes preencham seus dados e enviem uma mensagem.

O formulário possui:

- Nome;
- E-mail;
- Assunto;
- Mensagem;
- Botão para envio.

Foram utilizados elementos como:

`<form>`, `<fieldset>`, `<label>`, `<input>`, `<select>`, `<textarea>` e `<button>`.

### 🦶 Rodapé

O rodapé apresenta informações sobre o projeto e formas de contato por:

- 📧 E-mail;
- 📱 Telefone.
